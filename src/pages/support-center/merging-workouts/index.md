If you record one session as several activities, such as a warm-up, a track session and a cool-down, or you changed shoes partway through, each arrives in Chiron as a separate workout. Merging combines them into one workout, so your schedule shows the session as you planned it.

## Merge workouts

1. Open one of the workouts.
2. Tap the **⋮** menu and choose **Merge/Unmerge**.
3. Chiron lists the other workouts of the same activity type on the same day. Select the ones to merge.
4. Confirm. You'll see **Workout merged successfully!**

Only workouts of the same activity type on the same date can be merged. If there are none, Chiron says there are no workouts to merge on that date.

## Unmerge

Open the merged workout, tap the **⋮** menu, choose **Merge/Unmerge** again and deselect the activities you want to split back out.

## Who can merge

Only the athlete can merge their own workouts. Coaches can't merge workouts on an athlete's behalf, because only the athlete knows whether a split was intentional.
